# oline documentation

These pages explain how to build, run, and configure oline. Start with the first
one.

- [Getting started](getting-started.md) - requirements, build, API key, running,
  and the command-line flags.
- [The interface](tui.md) - the splash screen, the setup wizard, the running view,
  and the keybindings.
- [Agents, modes, and tools](agents.md) - the pentester and exploiter rosters, how
  the orchestrator works, the tool set, and time budgets.
- [Configuration, secrets, backups, and logs](configuration.md) - the oline root,
  config files, model and provider settings, API keys, backups, and the activity
  log.
- [Sandbox and egress](sandbox.md) - the WSL and QEMU backends, the per-agent
  network boundary, the deny patterns, the workspace, and VPN support.

For an overview of the project, see the [main README](../README.md).

> Authorized use only. Run oline exclusively against systems you own or have
> explicit written permission to test.
